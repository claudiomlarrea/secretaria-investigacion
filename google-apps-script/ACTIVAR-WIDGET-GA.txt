WIDGET DE VISITAS (números en la página, desde Google Analytics)
================================================================

Una sola vez en Apps Script (~5 min):

1) script.google.com → Publicaciones Página Web → SyncLookerOpenAlex.gs
   Pegá el PublicacionesWeb.gs de esta carpeta (versión con action=stats).

2) Servicios (+) → agregar "Google Analytics Data API".

3) Menú engranaje → Configuración del proyecto → abrir Google Cloud
   → Biblioteca → habilitar "Google Analytics Data API".

4) Implementar → Administrar implementaciones → lápiz → Nueva versión.

5) Probar en el navegador:
   .../exec?action=stats
   Debe responder: {"ok":true,"secretaria":12,"observatorio":95,...}

Las webs ya tienen visitantes.js; recargá con Cmd+Shift+R.

PUBLICACIONES SECRETARÍA — un solo paso en Google (5 minutos)
=============================================================

1. Abrí: https://script.google.com → Proyecto NUEVO (+)

2. Borrá Code.gs y pegá TODO el archivo:
   PublicacionesWeb.gs   (de esta carpeta)

3. Archivo → Nuevo → HTML → nombre exacto: PublicacionesAdmin
   Pegá TODO PublicacionesAdmin.html

4. Implementar → Nueva implementación → Aplicación web
   Ejecutar como: Yo | Acceso: Cualquier usuario de Google → Implementar

5. Copiá la URL que termina en /exec

6. En tu Mac, abrí js/publicaciones-config.js:

   APPS_SCRIPT_URL: "LA_URL_QUE_COPIASTE",
   ADMIN_URL: ""

7. git add js/publicaciones-config.js && git commit -m "Conectar API publicaciones Secretaría" && git push

   (O avisame y lo subo yo.)

NO pegues estos archivos en el proyecto del Observatorio salvo que quieras unificar.
Misma planilla; acceso panel solo por correo Google autorizado.

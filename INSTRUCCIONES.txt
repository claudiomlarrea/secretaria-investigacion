PASO 4 — Cada vez que edites el sitio en Cursor
--------------------------------------------------------------------------------

1. Guardá los archivos en Cursor (index.html, css/, etc.).

2. En Terminal:

   cd ~/Documents/secretaria-investigacion
   ./publicar.sh "Breve descripción del cambio"

   (O sin script:)
   git add -A
   git commit -m "Breve descripción del cambio"
   git push

3. Esperá 1–2 minutos. Recargá el sitio en vivo con Cmd+Shift+R.

4. El Google Sites de siempre NO se actualiza solo. Solo cambia la URL de arriba.

  Ver archivo google-sites-redireccion.html y los pasos abajo.

--------------------------------------------------------------------------------
PASO SUAVE — Redirigir Google Sites al sitio nuevo (hacelo vos en el editor)
--------------------------------------------------------------------------------

1. Abrí el sitio actual como EDITOR:
   https://sites.google.com/uccuyo.edu.ar/tablero-de-investigacion/inicio

2. Entrá a la página INICIO (la que todos usan).

3. Opcional pero recomendado: ocultá o borrá los bloques viejos de botones
   (Consejo, Ordenanza, anexos…) para que no se vean debajo del aviso.
   O dejá solo un bloque de texto arriba y el incrustado abajo.

4. Menú Insertar → Incrustar → Pestaña "Incrustar código".

5. Abrí en tu Mac el archivo:
   ~/Documents/secretaria-investigacion/google-sites-redireccion.html
   Copiá TODO y pegalo en el cuadro de código.

6. Ajustá el tamaño del bloque incrustado si hace falta.

7. Arriba a la derecha: PUBLICAR (no solo Guardar).

8. Probá en ventana de incógnito:
   https://sites.google.com/uccuyo.edu.ar/tablero-de-investigacion/inicio
   Deberías ver el mensaje breve y luego el sitio:
   https://claudiomlarrea.github.io/secretaria-investigacion/

Si Google Sites NO acepta el script (no redirige):
  - Dejá solo el botón "Ir al portal ahora" del mismo archivo, o
  - Un bloque de texto con enlace grande al sitio nuevo.

Para volver atrás: editá Inicio otra vez, borrá el incrustado y Publicá.
